# SOUR BEACH landing page

Static responsive landing page concept in Russian.

## Run

Open `index.html` in a browser. No build step or package installation is required. The Google Fonts link is optional; the page falls back to system fonts when offline.

Prices, product availability, and order submission are deliberately marked as demo placeholders. The cart is an in-page interaction only.

## Files

- `index.html` — page structure and copy
- `style.css` — responsive styling
- `app.js` — demo cart interaction
- `sour-beach-can.png` — the supplied three-view SOUR BEACH can artwork used by the page
